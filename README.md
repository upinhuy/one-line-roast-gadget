Entry for the [make.fun bounty "One-Line Roast: The Gadget You Use Every Day"](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) — one original line, at most 200 characters, roasting a gadget used every day.

## The entry

> My robot vacuum has mapped every corner of my house and still eats the same phone charger every single day.

## How it works

`main.ts` writes that single line to `/output/entry.txt`, where the house gate scorer reads it (UTF-8 text, 1–200 characters). It validates the length first and refuses to write an out-of-range line.

```sh
node main.ts
```
